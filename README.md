# Scarface Performance Suite

Crie um painel de otimização totalmente funcional, na qual tem funções de limpar memoria, otimizar gpu, otimizar cpu, otimizar windowns, modos para jogos etc... utilize as melhores ferramentas para desempenho para o computado, utilize a imagem como exemplo para o painel, faça sistema de login unico no painel, na qual eu poderei criar logins para as pessoas e lembre o nome do painel é SCARFACE OPTIMIZER
